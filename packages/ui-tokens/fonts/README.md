# Pretendard

Unmodified Pretendard Variable v1.3.9, shared by both site surfaces.

- Upstream: https://github.com/orioncactus/pretendard/tree/v1.3.9
- Font: https://raw.githubusercontent.com/orioncactus/pretendard/v1.3.9/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2
- License: https://github.com/orioncactus/pretendard/blob/v1.3.9/LICENSE
- Distribution: retain the copyright notice and SIL Open Font License in `OFL.txt` alongside the font. No font modifications.
- Payload: 2,057,688 bytes, complete Korean/Latin variable face. One same-origin file; no runtime CDN or font package dependency. `font-display: swap` keeps fallback text available while loading.

The public exporter accepts only this exact WOFF2 path and pinned SHA-256. Font updates require updating the digest and rerunning export/browser checks.
